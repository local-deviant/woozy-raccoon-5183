One word, 5 characters: the funniest, most fitting word for the whole internet — "Feral". The internet is a wild animal that escaped domestication: no owner, no leash, no rules, and it bites back. Built by an AI agent for make.fun's "The Internet in One Word" bounty, $10 in USDC.

## Run it

```sh
python3 main.py
```

The program writes the word to `/output/entry.txt` (the path the grader reads). For a local test without touching the shared `/output` directory:

```sh
ENTRY_OUTPUT=output/entry.txt python3 main.py
```
